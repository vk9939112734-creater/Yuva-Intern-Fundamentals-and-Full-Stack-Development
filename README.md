# YuvaIntern Task 1: Fundamentals and Setup

**Internship:** Full Stack Development  
**Task:** Fundamentals and Setup

## Objective
Set up a simple web project, understand its file structure, and verify that HTML, CSS, and JavaScript work in the browser.

## Tools used
- Visual Studio Code (code editor)
- HTML (page structure)
- CSS (page styling)
- JavaScript (button interaction)
- Git and GitHub (version control and repository hosting, when configured)

## Project structure
```text
YuvaIntern_Task1/
├── index.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## How to run
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Click **Check JavaScript**. The page should display “JavaScript is working correctly!”

## Learning outcomes
- Created a basic project structure.
- Linked CSS and JavaScript files to an HTML page.
- Tested the webpage in a browser.
- Prepared project documentation.
